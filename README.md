# REON Controller

REON Pocket Pro Plus向けのWeb Bluetoothコントローラ。白基調のLiquid Glass UI、モバイル・PC対応。M5StickS3の加速度に合わせ、静止時は冷却、動きが大きくなるほど温熱へ出力を変えられます。

## 起動

Node.js 24以降で `node server.js` を実行し、http://localhost:4173 を開きます。本体のSMARTボタンを約2秒押し、デバイスを接続します。本体を選ぶ操作はブラウザの要件です。「接続して運転」またはプリセットから接続と開始をまとめて行えます。

配信はWorker ESMとR2です。`node scripts/build.mjs` でビルドし、Sitesのソース同期・パッケージ・配信ワークフローで公開します。SitesのIDは `.openai/hosting.json` に保存しています。

## 操作

- 冷却・温熱・SMART、レベルの直接選択、開始・停止、静か／標準／強力のプリセット。
- 本体が報告する機能と最大レベルに追従します。非対応機能は無効になります。
- オフタイマー、ウェーブ、オートスタート／ストップ、クイック起動。
- デモは明示的に開始します。デモ中は本体へのコマンドを送信しません。
- 全画面スケルトンは初回読み込みに表示。Bluetooth接続中は画面を覆わず、進行状況とキャンセルを表示します。設定からスケルトンを再確認できます。
- OSの動きを減らす設定とアプリ内のアニメーション設定に対応します。

## 外部センサー

### M5StickS3の加速度

M5StickS3専用のBluetooth LEファームウェアは `firmware/m5sticks3-motion/` にあります。手順は同フォルダの `SETUP.md` を参照してください。WebアプリのM5StickS3カードから接続し、「加速度連動」をオンにします。REONとM5は別々にBluetooth接続します。

動きは `|sqrt(x²+y²+z²) - 1| G` として評価します。重力約1Gからの合成加速度のずれであり、姿勢推定を用いた厳密な線形加速度ではありません。デフォルトでは0Gが冷却3、0.5Gが停止、1G以上が温熱2です。最大温熱になる動きの値と、冷却・温熱の上限を編集できます。摂氏温度の直接指定ではなく、本体の対応レベルへ変換します。

受信周期は200ms（5Hz）。平滑化・ヒステリシス・切替の待機時間は入れません。加速度が1.5秒更新されない場合やM5切断時は、連動を解除して停止コマンドを送ります。解除後・期限切れの未送信コマンドは破棄します。再受信しても自動では再開しません。手動操作と周囲温度連動は加速度連動を解除します。連動スイッチをオフにするだけの場合は現在の出力を維持します。

「デモを試す」で加速度スライダーを表示し、実機に送信せず試せます。M5の加速度表示はREON未接続でも確認できます。REON側に `owner.write` エラーが残る場合、実機の冷却・温熱連動はその接続問題の解消後に利用できます。

### 周囲温度

REON Pocket Tag、またはCORS対応のJSON APIに対応しています。Tagは本体に接続したうえで登録します。Bluetooth広告読み取りが非対応のブラウザではTagの新規登録ができません。

APIの例:

```json
{"temperature":28.5,"humidity":62,"timestamp":"2026-10-20T06:00:00.000Z"}
```

`temperature` は−40〜80°Cの必須数値、`humidity` は0〜100の任意数値です。`timestamp` はISO 8601またはUnixミリ秒の任意値で、省略時は受信時刻として扱います。指定時は30秒以内の値を受け付けます。センサーURLはHTTPS、ローカル開発用のlocalhostのみHTTP可。URLへの認証情報埋め込みは不可です。APIは `Access-Control-Allow-Origin` でアプリのオリジンを許可してください。アプリはリクエストに認証Cookieを送信しません。

取得間隔は1・2・5・10秒から選べます。リクエストは重複させず、応答とBluetooth送信が完了してから次の取得を予約します。ブラウザや通信の遅延によって実時間隔は延びます。

「温度と出力の対応」で温度境界・冷却／温熱／停止・レベルを編集し、「センサー連動」をオンにします。各行は設定温度以下に適用され、最後の行はそれ以上にも適用されます。受信した有効値を毎回評価し、対応コマンドを送ります。ヒステリシス、平滑化、切替の待機時間、デバウンスはありません。GATTのコマンドは順番に送信します。

元の通信仕様で扱える出力レベルへの対応であり、プレートを任意の摂氏温度に直接設定するものではありません。本体の対応レベルを超える設定は対応上限に制限します。手動操作はセンサー連動を解除します。センサー連動オフのみでは現在の出力を維持し、運転停止ボタンで停止できます。

更新が30秒途絶えた場合はセンサー連動を解除して停止コマンドを送ります。ブラウザがバックグラウンドで休止した場合はタイマーや取得が遅れ、復帰時に期限を確認します。ブラウザを閉じた後やOSが休止した状態での継続制御はできません。Bluetoothが切れた後の本体停止は保証できないため、必要な場合は本体ボタンを使用してください。

## 検証

Bun 1.4.2で `bun install --frozen-lockfile`、`bun test`。テストは155件です。

- 元リポジトリのプロトコルのバイト列テストを継承。デバイス選択の無応答・キャンセル・時間切れ・遅延応答・権限拒否を含む回帰テスト。
- センサー境界値、交互入力、機種上限、入力検証、タイムスタンプ。
- 同時通信を拒否する模擬GATTによる接続・認証・通知・送信順序・エラー・切断。
- Happy DOMによる画面操作、接続と開始、プリセット、センサー連動、API、タイマー、設定保存。
- M5のBLEパケット、シーケンス周回、切断・期限切れ、冷却から温熱への連動、手動操作の優先、送信待ちコマンドの無効化。
- M5StickS3ファームウェアはPlatformIOでビルド成功。使用バージョンとメモリ使用量は `firmware/m5sticks3-motion/BUILD-INFO.txt` に記録。
- ブラウザでPCと390pxモバイルの表示、デモ操作、センサー連動、横はみ出しとコンソールエラーを確認。

実機・実センサーはこの環境にないため、実機との通信と温度変化は未検証です。元実装の検証対象はRNP-P1 / Firmware 2.2.1で、Pro Plusとの互換性を保証するものではありません。

## 接続が進まない場合

Chromeで本体が選択できた後の `NotSupportedError` は、ブラウザ全体の非対応と断定しません。エラー下の「接続の詳細」に、失敗した処理（`owner.write`、`capability.read` など）、Chromeの元のエラー名・メッセージ、取得できたモデル・ファームウェア・各項目の対応属性を表示します。認証キーや書き込みペイロードは診断情報に含めず、自動送信もしません。「詳細をコピー」から共有できます。接続成功時も設定画面から確認できます。

書き込みは本体が報告する `write` / `writeWithoutResponse` の属性に合わせます。通知が非対応で読み取りが可能な項目は5秒ごとの定期取得に切り替え、書き込みと直列に実行します。表示用の機種情報や任意のテレメトリ項目だけが非対応の場合は、その項目を取得せずに操作接続を継続します。通知でのみ取得できる運転状態については、実際の通知を受け取るまで現在値を確定しません。機能情報や操作に必要な通信が非対応の場合は、処理名を表示して接続を中止します。

接続中に全画面ローディングは表示しません。「ブラウザのデバイス選択待ち」ではブラウザが出す選択画面を確認してください。「キャンセル」で接続待ちを中止できます。選択画面が開かない場合は、表示されたURLをコピーしてChrome / Edgeなどの対応ブラウザで直接開きます。選択待ちは45秒、本体選択後の初期化は20秒で時間切れとして解除します。キャンセルや時間切れ後に届いた古い選択結果は採用しません。ブラウザの機器選択画面自体はWeb APIから閉じられないため、残っている場合はブラウザ側でも閉じてください。

## 対応ブラウザ

Chrome / Edgeのデスクトップ、Android ChromeなどWeb Bluetooth対応環境が必要です。iPhone / iPadではBluefyなど対応ブラウザが必要です。Safari / Firefoxは本体との接続に対応しません。Sites内の埋め込み表示でBluetoothが利用できない場合はURLを対応ブラウザで直接開いてください。

## 人物間の距離

映像から0〜100の距離スコアを算出するサービスを追加。入口は /distance。REON画面の「人物間の距離」カードで参照・画面内解析、別端末では共有JSON APIを利用できます。技術選定の全理由、距離の定義、API契約、利用条件は DISTANCE.md に記載しています。

配信は静的ホスティングからWorker ESMとR2へ移行しました。ローカル起動前に node scripts/build.mjs を実行してください。既存のBluetoothモジュールは維持しています。
