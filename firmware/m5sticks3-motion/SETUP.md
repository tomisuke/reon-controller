# M5StickS3 → REON Bluetooth加速度連動

## 接続構成

M5StickS3の内蔵BMI270 → Bluetooth LE → PCのChrome/Edge → Bluetooth LE → REON本体。

M5StickS3は加速度だけを送ります。REONの操作はWebアプリが行います。Wi-Fi設定、スマホの公式アプリ、サーバーへのセンサー送信は不要です。Webアプリを開いている間だけ連動します。

## 1. M5StickS3へ書き込む

専用ファームウェアを書き込むと、M5StickS3で現在実行しているプログラムが置き換わります。必要なソースや設定は先に保存してください。本手順でREON本体のファームウェアや登録情報は変更しません。

PlatformIOを使用します。VS CodeのPlatformIO拡張、または `python -m pip install platformio` でCLIを用意してください。

1. ZIPを展開し、`platformio.ini` があるフォルダを開きます。
2. データ通信対応のUSBケーブルでM5StickS3をPCへ接続します。
3. ターミナルで `pio run -t upload` を実行します。複数の機器がある場合は `pio run -t upload --upload-port COM番号` と明示します。
4. 画面に `REON Motion`、`BLE: READY`、加速度が表示されれば準備完了です。

コンパイル用の基板設定はM5Stack公式StickS3のPlatformIO設定に基づきます。ESP32 ArduinoコアのBLEライブラリ、M5UnifiedとM5PM1を使用します。初回はSDKとライブラリのダウンロードが必要です。

書き込み済みデータの保存方法やダウンロードモードの操作は、[M5Stack公式StickS3ガイド](https://docs.m5stack.com/en/core/StickS3) を参照してください。

## 2. ブラウザで2台を接続

1. [REON Controller](https://tomisuke.github.io/reon-controller/) をPCのChrome/Edgeで開きます。
2. REON本体を「デバイスを接続」から接続します。
3. M5StickS3カードの「加速度センサーを接続」を押し、`M5StickS3-REON` を選びます。
4. X/Y/Zと動きの値が更新されることを確認し、「加速度連動」をオンにします。

M5だけを先に接続して加速度の表示を確認することもできます。REONが未接続の場合、連動は開始しません。以前の `owner.write` エラーが残っている場合は、加速度の受信は確認できますが、REONへの出力は実行できません。

## 3. 温度への対応

動きの指標は `abs(sqrt(x*x + y*y + z*z) - 1)` Gです。静止時に観測される重力約1Gからのずれを使い、固定姿勢を変えても静止時はほぼ0Gになります。これは重力ベクトルを姿勢推定で厳密に除去した線形加速度ではありません。等速移動、ゆっくりした回転、重力に直交する小さな加速は反応が小さいことがあります。

初期設定は「最大温熱になる動き」1.0G、冷却の上限3、温熱の上限2です。

| 動き | 出力の例 |
| --- | --- |
| 0G（静止） | 冷却3 |
| 0.25G | 冷却2 |
| 0.50G | 停止 |
| 0.75G | 温熱1 |
| 1.00G以上 | 温熱2 |

感度と冷却・温熱の上限はWebアプリから変更できます。出力はREONが報告する対応レベルの範囲に収まります。任意の摂氏温度を直接指定する方式ではありません。

平滑化、ヒステリシス、切替の待機時間はありません。M5は200msごと（5Hz）に測定値を送ります。受信した有効な値ごとに対応する出力を評価し、REONのGATT処理へ順番に渡します。実際の温度変化には本体の応答時間があります。

## 停止と優先操作

- 運転停止、手動レベル選択、モード変更、プリセットは加速度連動を解除します。
- 周囲温度によるセンサー連動と加速度連動は同時にオンになりません。
- 加速度連動のスイッチだけをオフにした場合は、現在の出力を維持します。停止ボタンで運転を停止できます。
- M5切断、または有効な加速度が1.5秒更新されない場合は、連動を解除して停止コマンドを送ります。再受信しても自動再開しません。
- 解除済み・期限切れの加速度コマンドは、送信待ちであっても破棄します。すでに進行中のBluetooth書き込みは取り消せません。
- ブラウザやOSが休止した場合、取得・停止処理も遅れることがあります。REONのBluetooth接続自体が切れた場合は、本体ボタンで停止してください。

## 動作の確認

「デモを試す」でM5カードに動きのスライダーが現れます。「加速度連動」をオンにすると、0Gの冷却から大きな動きの温熱へ変わることを、実機へ送信せず確認できます。

## BLEパケット仕様

Service: `51b92800-d766-4aa7-b64d-3f1ab08b1260`

Characteristic（Read / Notify）: `51b92801-d766-4aa7-b64d-3f1ab08b1260`

20バイト、リトルエンディアン。標準ATT MTUのままで通知可能な長さです。

| バイト位置 | 型 | 内容 |
| --- | --- | --- |
| 0 | uint8 | バージョン1 |
| 1 | uint8 | bit0: IMUデータ有効 |
| 2 | uint16 | シーケンス番号 |
| 4 / 8 / 12 | float32 | X / Y / Z（G） |
| 16 | uint32 | 起動からのミリ秒 |

重複・逆順シーケンス、無効フラグ、不正な数値は採用しません。65535→0の周回に対応します。鮮度は受信側の時刻で判定します。M5は最新のIMU取得が100ms以上前のとき無効フラグを送ります。
